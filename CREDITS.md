## Assets

- UI type: system sans stack; mono: JetBrains Mono / SF Mono / system monospace. No web fonts.
- Every visual — graph, favicon, icon, posters, OG card — is generated by this project.
- Thumbnails imported by the user come from YouTube and are stored locally as data URLs. They are not

## Data

No video corpus is shipped. The optional `benchmark/library-100k.json` fixture is synthetic, generated
locally, gitignored, and labelled as such; it is never presented as real viewing history.
